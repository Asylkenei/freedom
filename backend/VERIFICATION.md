# Проверка backend и инструментов качества

Дата: 7 ноября 2026 года. Реализация, подключение и точность отмечены отдельно.

## Программные проверки

Команда: `python -W always::ResourceWarning -m unittest discover -v`.

Результат: **110 тестов, OK**. Сохранены 38 тестов baseline: расчёт, N/A, шкалы, роли, источники, апелляции и benchmark. Новые проверки покрывают Responses, API, очередь, кэш, перезапуск, CORS, версии чек-листов, идемпотентные решения, ревизии, каскад, предел вызовов, нерешённый эталон, ошибки API в метриках, слепые CSV/JSON и неизменность данных. CSV проверен на Unicode, кавычки и переносы строк. Незавершённый шаблон нельзя экспортировать как gold.

HTTP-фикстуры проверяют FastAPI → worker → Responses HTTP → валидатор → SQLite → API. Они синтетические и не измеряют качество настоящей модели.

## Реальный каскад

На одном уже использованном RU-чате проверена цепочка gpt-6-luna → gpt-6.1-sol с обязательным вторым этапом. Ровно 2 вызова, без повторов/переключения. Время 26.687 с; input 13 356, output 3 038, total 16 394. Оценка токенов $0.0294375 с теми же ограничениями. [Luna](https://developers.openai.com/api/docs/models/gpt-6-luna).

Итог needs_review, балл null. Модели разошлись по c02/c04. Это проверка цепочки, не доказательство превосходства каскада.

Luna вернула c04=20 одновременно с factual_status=not_verified. После этого добавлен регрессионно проверенный барьер: явно непроверенный факт превращает балл в needs_review даже без второго вызова. Сохранённый реальный raw-ответ воспроизведён через новый валидатор: c04 корректно нерешённый, дополнительных вызовов не было. Версия обработки изменена; исторические ответы не переписаны.

## Независимая разметка

DEV проверен: 65 уникальных ID, 30 RU-чатов, 15 KZ, 15 EN, 5 RU-звонков. Подготовлены слепые development=45/test=20, CSV/JSON и читаемые транскрипты. Четыре smoke-диалога только в development. Точных дублей нет; похожих пар между частями с ratio >=0.92 по client/operator не найдено. Эвристика не исключает смысловые повторы.

Есть пилот 10 development-диалогов, 80 пустых меток. **Согласованных человеческих меток сейчас 0.** PDF задаёт критерии, не готовый gold. Отдельный продуктовый справочник не предоставлен. Фикстуры и LLM-ответы не названы человеческой разметкой.

Следовательно, точность, MAE на 65 диалогах и полнота обнаружения нарушений не измерены. Реализованы инструменты для такого измерения. Основной сервер остаётся в single-режиме. Все 65 диалогов автоматически не отправлялись: четыре успешных одиночных запроса и два запроса отдельного каскада.

## Передача

README: запуск, оба режима, разметка, gold, эксперименты, метрики. FRONTEND_INTEGRATION: чек-листы, апелляции, решения, состояния. OpenAPI экспортирован. Примеры в examples синтетические, включая исходные 100 и финальные 90 после ручной замены.

Перед обновлением сохранена приватная копия data/backups/before-phase2.sqlite3. Миграция сохраняет историю. .env, базы, транскрипты, реальные ответы, разметка и журналы исключаются из архива. Предыдущий frontend MVP не изменяется.

Для завершения проверки качества команде нужно разметить и согласовать пилот, затем набор, сравнить варианты на development и проверить зафиксированную конфигурацию на holdout. Готовность backend не означает завершение этой человеческой работы.
