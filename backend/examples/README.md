# Синтетические примеры API

Все файлы этой папки созданы с программной фикстурой на вымышленном диалоге. Это примеры формата для frontend, **не реальные ответы OpenAI и не эталонные оценки качества**.

- `import.json` — тело импорта; можно отправить в POST `/api/conversations/import`.
- `checklists.json` — официальный чек-лист с hash.
- `conversation.json` — сообщения со стабильными ID и история запусков.
- `evaluation.completed.json` — завершённая оценка.
- `evaluation.needs_review.json` — неопределённый критерий, полный балл `null`.
- `evaluation.error.json` — ошибка провайдера, `result=null`.
- `checklist.save.json` — тело сохранения новой версии чек-листа.
- `appeal.create.json` — тело создания апелляции с ID запроса.
- `appeal.resolve.json` — тело решения с ревизией и заменой критерия.
- `evaluation.reviewed.json` — сохранённая исходная оценка 100 и финальная 90 после синтетической апелляции. У вымышленного оператора отсутствует представление; программная фикстура намеренно не проверяет семантику, человек в примере исправляет c01.

Реальные данные, ошибки доступа с реальными запросами, результаты и отчёты живут только в исключённой папке `data/`.
