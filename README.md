# Earth 616 — Freedom Broker CQA

Команда: **Earth 616**. Data Challenge 2026.

Система оценки работы оператора по восьми критериям официального чек-листа. Python 3.11+, FastAPI, SQLite, OpenAI Responses API. Поддерживает RU/KZ/EN, точные цитаты, проверку ролей и баллов, N/A, историю запусков и ручную проверку. Итог считает Python.

## Запуск

```sh
cd backend
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
cp .env.example .env
# заполнить CQA_API_KEY в локальном .env
.venv/Scripts/python -m uvicorn app:app --host 127.0.0.1 --port 8000 --workers 1
```

Документация: http://127.0.0.1:8000/docs. Подключение frontend описано в backend/FRONTEND_INTEGRATION.md. Ключ хранится только на сервере.

## Результаты

`results/prod/results.json`: 10 контрольных чатов FBroker, обработанных одной gpt-6.1-sol. Неопределённые оценки представлены как error по правилам приложения, а не как нулевой балл. 1 полный результат, 9 требуют проверки. SWAP сохранён локально без оценки и не включён в prod.

`results/dev/results.json`: все 65 исходных ID. Полный DEV-прогон не завершён до сдачи; записи честно обозначены error. Это ограничение результата.

## Сравнение моделей

10 пилотных диалогов, 30 реальных вызовов: одна gpt-6.1-sol против gpt-6-luna + независимая gpt-6.1-sol. Обе схемы совпали с разметкой ИИ по 66 из 75 определённых меток (88%). Это согласие с ИИ, не независимая человеческая точность. Среднее время: 15.45 с и 36.55 с. Оценочная цена десяти диалогов: $0.353228 и $0.377206. Выбрана одна модель. Цена рассчитана по usage, включая кэш, не счёт аккаунта.

115 автоматических тестов прошли. В пилоте основной блокер — проверка продуктовых фактов c04 при отсутствии справочника. Неизвестный факт ведёт к ручной проверке; результат не выдумывается.
